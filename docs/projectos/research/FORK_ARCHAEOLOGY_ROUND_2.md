## Selected commit evidence and next tests
Each URL is an observed commit tip; excerpts inspected, not a full branch audit. Do not implement from this document as if it were an approved clean-room specification. Licensed FOSS reuse and independent implementation are separate tracks.
- F-01 https://github.com/Extravert-ir/reactos/commit/118f5cd5ace47d46e02f239855e0becb45df19dc — FAT FreeLoader tracks clusters incrementally instead of allocating whole cluster chain and groups adjacent reads. Author reports allocation ceiling around 256 KiB and opening files spanning >65k clusters. Test fragmented/contiguous images, random seeks, cyclic/invalid cluster chain, short reads, FAT variants, allocator high-water and I/O count. Check current upstream behavior first; preserve all notices when reviewing header changes.
- F-02 https://github.com/maharmstone/reactos/commit/f79381e5fa59dada4375ac605c2afa439c7bab7d — unaligned Btrfs read path uses sector-sized temporary allocation instead of size-plus-offset buffer. One commit against upstream. Test arbitrary offsets, length around boundary, EOF, 512/4K disk geometry, I/O errors and allocation failure. No claims about measured savings yet.
- F-03 https://github.com/maharmstone/reactos/commit/98880e55aa6bf4ca24dfa8313783b38d92a94adf — tip is style-only; branch handles sparse extents by zero filling. Locate actual functional parent, compare equivalent upstream fix, test multi-extent/sparse reads and corrupt metadata; no data-loss claims.
- F-04 https://github.com/TheNNX/reactos/commit/41b38f007503cfb9c4d2551878d7f37097f3b625 — CORE-17655; process query and Wow64Process allocation/free path, with explicit unfinished-work comments. Five commits vs upstream, 10 files. Inspect query status/buffer length, rundown protection, quota rollback, cancellation, process teardown, IRP thunking and context switch. Upstream CI reference https://github.com/reactos/reactos/actions/runs/23985460893; artifacts reportedly expired; build not verified here.
- F-05 https://github.com/vgalnt/reactos/commit/8878620209dc27e5f64bcfa122c7672549adf8c2 — CORE-13344, SVN r75658, original GSoC xHCI work by Rama Teja Gampa, GPLv2+ headers visible; stop controller, INF descriptions, logging. Modern stack now reportedly basic-merged; historical work is primarily a regression and design source. Test controller stop/reset, transfer cancellation, disconnect, DMA and power. Do not copy without per-file provenance and current applicability review.
- F-06 https://github.com/vgalnt/reactos/commit/45fb6e791af8b934dc0a3bac01bed10e3abf74a5 — final commit confines a boot-blocking diagnostic pause to debug builds. Test boot driver readiness, no implicit delay dependency, debug/release parity and concurrent enumeration. PnP was substantially rewritten upstream later.
- F-07 https://github.com/andrew-boyarshin/reactos/commit/a54b334625a43fd56ab889369aa28e2382d9cbc1 — one commit, variable-name spelling correction only in MiCheckForUserStackOverflow; no functional gain established. Deprioritize; demonstrates false positive from branch name.
- F-08 https://github.com/DarkFire01/reactos/commit/ace52cdbb5732305b1145246454d0bcc96241467 — CORE-18200 ARM64 debug services assembly and build wiring, new file MIT notice observed; five commits vs upstream. ## Primary historical reports and missed angles
- https://reactos.org/project-news/oct-hackfest-2026/ — reports physical AMD64 SMP uptime >2 days, NT6 shim work and initial modern USB stack merged. Reconcile exact upstream SHAs, no production support inference.
- https://reactos.org/project-news/reactos-0416-released/ — graphical combined installer, system PTE exhaustion behind GPU slowdown, ExtEscape fix, new ATA driver, KMDF and HD audio, async networking. Audit cross-subsystem failure root causes rather than assuming a graphics or network bug is local.
- https://reactos.org/project-news/january-2017-meeting-minutes/ — several GSoC branches did not yet run on ReactOS despite Windows tests; Vadim's USB and GSoC were separate modules. Historical evidence only. Map prerequisites and avoid resurrecting outdated work.
- https://reactos.org/blogs/gsoc-2018-final-report/ — Extravert's gsoc2018_all branch and PR, initial Btrfs boot support single-disk/uncompressed. Trace upstream integration and modern limits.
- https://reactos.org/blogs/gsoc-ntfs-2017-work-summary/ — experimental writes explicitly warned about data loss; historical gaps include caching, rename/delete, pagefile, async I/O, mapped files. DumpDrive image comparison was valuable; recreate an original safe differential test harness. Never enable experimental write against real data.
